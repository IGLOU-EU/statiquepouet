StatiquePouet demo

This page demonstrates fediverse-based comments on a static site. No script is loaded until you click a button.

The page declares an anchor post in its <head> via <meta name="fediverse-context">. The buttons below are plain HTML. Their onclick calls the small statiquePouet(action) function defined inline at the foot of the document.

To serve this demo, from the project root run make serve (or python3 -m http.server), then open localhost:8000/demo/index.html. file:// URLs do not work (CORS).
